# 每日签到 H5 原型

这是每日签到活动的可交互 H5 原型，用于产品方案讨论、UI确认和开发测试沟通。

## 当前原型包含

- 累计签到天数展示
- 每日任务状态
- 今日礼盒签到交互
- 每日奖励与连续7天加赠奖励弹窗
- 模拟完成任务与重置演示

## 文件说明

- `index.html`：完整原型，包含页面样式和交互，无需安装依赖

## 本地查看

直接用浏览器打开 `index.html`。

## Cloudflare Pages

连接本仓库后无需构建：

- Framework preset：None
- Build command：留空
- Build output directory：`.`

后续产品逻辑调整和 Cursor 生成内容统一在本仓库维护。
